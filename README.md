## 🚀 Featured Project

### De-NodulosPulmon-Rx

<sub>Academic / Research Project · 2024 — 2025</sub>

A web platform developed to support the study, detection, and classification of pulmonary nodules using web technologies and machine learning.

**Architecture & Backend**
- Developed a REST API with NestJS and TypeScript.
- Organized the backend using controllers, services, DTOs, and modular architecture.
- Implemented JWT authentication, token renewal, and role-based access control.
- Used PostgreSQL and Prisma ORM to manage a relational model with more than 10 entities.

**Frontend**
- Built a Single Page Application using Angular 19.
- Integrated Taiga UI and RxJS / BehaviorSubject for reactive state management.

**Machine Learning Integration**
- Integrated YOLOv5 for pulmonary nodule detection.
- Used Random Forest for classification.
- Connected Python-based machine learning services through Flask APIs.
