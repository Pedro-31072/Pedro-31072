## `04` — Featured Project

### 🫁 De-NodulosPulmon-Rx

**Full-Stack Medical Imaging Research Platform**

A web platform developed as my Computer Science degree project, focused on the study, detection and classification of pulmonary nodules in chest X-ray images.

**Architecture & Backend**
- Designed and implemented a modular REST API using NestJS and TypeScript.
- Applied separation of concerns through controllers, services and DTOs.
- Implemented JWT authentication, session renewal and role-based access control (RBAC).
- Designed a relational database with more than 10 entities using PostgreSQL and Prisma ORM.

**Machine Learning Integration**
- Integrated YOLOv5 detection and Random Forest classification models.
- Connected Python-based services through Flask APIs.
- Implemented image processing and management of model inference results.

**Frontend**
- Developed a Single Page Application using Angular 19.
- Built interactive interfaces with Taiga UI.
- Implemented reactive state management using RxJS and BehaviorSubject.

**Technology Stack**

`Angular 19` `NestJS` `TypeScript` `PostgreSQL` `Prisma` `Python` `Flask` `YOLOv5` `Random Forest`
